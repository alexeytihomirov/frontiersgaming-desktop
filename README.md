# FrontiersGaming desktop

The FrontiersGaming desktop app for Windows: the Quake Live demo player and studio, the HUD builder and the config
editor, working with your local Quake Live install. Download the installer from
[Releases](https://github.com/alexeytihomirov/frontiersgaming-desktop/releases/latest). The app updates itself from
the same place.

**Windows SmartScreen will warn when you start the installer** ("Windows protected your PC"; publisher: Unknown).
The app is not code-signed yet. Click **More info**, then **Run anyway**.

Every release carries `engine-sources-<version>.zip`: the GPL sources of the bundled WASM engine (wolfcamql plus our
patch series and build scripts).

Десктопное приложение FrontiersGaming для Windows: плеер демок Quake Live со студией, конструктор HUD и редактор
конфигов, работает с вашей установкой Quake Live. Установщик - в
[Releases](https://github.com/alexeytihomirov/frontiersgaming-desktop/releases/latest), обновления приходят оттуда же.

**Windows SmartScreen предупредит при запуске установщика** («Windows защитила ваш компьютер», издатель:
неизвестный). Приложение пока не подписано сертификатом. Нажмите **Подробнее**, затем **Выполнить в любом случае**.

В каждом релизе есть `engine-sources-<version>.zip` - GPL-исходники встроенного WASM-движка.
